# n8n-nodes-clickfunnel

Community n8n node for [ClickFunnels 2.0](https://www.clickfunnels.com/) — 52 resources, 200+ operations, webhook triggers.

## Installation

1. Go to **Settings → Community Nodes** in n8n
2. Enter `n8n-nodes-clickfunnel`
3. Click **Install**

## Authentication

1. Generate an API token in ClickFunnels: **Settings → API Access Tokens**
2. Create a **ClickFunnels API** credential in n8n with your subdomain and token

## Resources

Contacts, Orders, Products, Funnels, Pages, Courses, Forms, Fulfillments, Sales Pipeline, Shipping, Stores, Themes, Workspaces, Webhooks, and more — covering the entire ClickFunnels 2.0 API.
